Draw a high-fidelity product UI screenshot for a minimal Pomodoro timer web page, shown inside a desktop browser window.

Decision to validate: whether the "quiet paper" direction (warm off-white paper background, ink-dark digits, one muted brick-red accent, no decoration) feels calm and focused enough for an office worker who keeps the page open in a browser tab all day. This image is only for mood/temperament, not for exact proportions.
User and context: an office worker and a few colleagues; the page sits in one browser tab while they work in other tabs and apps.
Device: desktop browser window, 1440x900, 16:9 framing.

Information hierarchy:
1. Primary focus: the remaining time "24:59", by far the largest text on the page, light weight, tabular digits, dark ink color.
2. Secondary content: a small phase label "专注" above the time, in a muted brick-red; below the time, nothing else in this state.
3. Actions: one solid primary button "暂停" (brick-red background, white text, medium corner radius about 8px) and one quiet text-style button "跳过" next to it, visibly weaker than the primary button.
4. Footer line: small muted text "今天完成 3 个" near the bottom of the content column.
5. Browser tab title shows "24:59 · 专注" at the very start of the tab.

Design system:
- Color tokens: page background warm paper #FAF8F4; main text ink #22201C; secondary text #5F5A52; hairline border #DDD8CF; focus accent brick red #A3412D; no other colors.
- Typography: system sans-serif (PingFang SC style for Chinese), the big digits in a thin/light weight; body 16px; small caption 14px.
- Spacing and radius: generous empty space, content in one centered column; buttons radius about 8px; no cards, no shadows.
- Density: very sparse.

Content constraints:
- Use these exact labels and only these: 专注, 24:59, 暂停, 跳过, 今天完成 3 个, browser tab "24:59 · 专注".
- No other text on the page: no logo, no navigation, no headline, no task list, no settings icon.

Avoid:
- Marketing hero composition, big headline, taglines
- Decorative gradient blobs, floating shapes, glassmorphism, purple-blue gradients
- Circular progress ring, glowing effects, illustrations, tomato icons, emoji
- Full-bleed colored background
- Text overflow or overlapping elements
