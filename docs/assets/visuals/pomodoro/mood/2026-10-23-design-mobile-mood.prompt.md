Information hierarchy:
1. Primary focus: remaining time "12:34", the largest text, light weight, tabular digits, dark ink color.

Design system:
- Color tokens: background warm paper #FAF8F4; main text #22201C; secondary text #5F5A52; hint text amber-brown #85561A; focus accent brick red #A3412D.
- Typography: system sans-serif (PingFang SC style), big digits thin/light; body 16px; caption 14px.
- Spacing and radius: one column, generous vertical breathing room, no cards, no shadows.
- Density: sparse; everything fits in one screen with no scrolling.

Content constraints:
- Use these exact labels and only these: 专注, 12:34, 已暂停, 继续, 跳过, 今天完成 3 个, 这个浏览器不能保存记录，刷新后今天的完成数会清零.

Avoid:
- Marketing hero composition, headline, logo, navigation bar inside the page
