# 设计变更日志

## [v1.0] - 2026-10-23

### 变更背景

PRD v1.0 与 Feature Spec 已确认，项目还没有任何设计文档和页面代码。需求方对外观的要求只有一句：「简洁、安静，不要花哨动效」。走 forge-design L1 完整设计，页面布局交给 forge-design-lab 工作台定稿。

### 设计方案

- **方向**：在三个方向里选了「纸面安静」——暖白纸底、墨色数字、两个低饱和阶段色（专注砖红、休息灰青）、系统字体、无阴影无卡片。
  - 落选「深色专注」：配色库给番茄钟的默认方案是深底 + 饱和红 + 绿，白天办公室里显得重，红绿对色弱用户难分。
  - 落选「整页阶段色」（Pomofocus 式按阶段换整页背景）：每次切段整屏变色，太吵。
- **气质稿**：用 Image 2 出了桌面和手机两张气质稿，确认方向够安静；比例不以气质稿为准。
- **布局**：在设计工作台的真 token 骨架上定稿，两轮审查。第 1 轮除「手机字号」外全部通过；工作台实测出手机横屏会把阶段标签顶出屏幕，第 2 轮按 A/B/C 选了「窗口矮于 480 也换手机字号」。

### 关键决策

| 议题 | 决定 | 原因 |
|---|---|---|
| 字体 | 系统字体，不用网络字体 | PRD 要求不从外部网址加载资源 |
| 阶段怎么区分 | 只换阶段标签和主按钮的颜色，并始终写着「专注 / 休息」 | 不靠整页变色，也不只靠颜色 |
| 主按钮颜色 | 用阶段色（采用），不用墨色 | 一眼知道在专注还是休息 |
| 手机上两个按钮 | 并排（采用），不上下叠 | 更轻；气质稿里的上下叠画法未采用 |
| 手机横屏溢出 | 加矮屏规则（采用 B） | 只修出问题的那一种窗口 |
| 动效 | 只保留按钮悬停变色 | 「不要花哨动效」 |
| 暗色模式 | 本版不做 | 越简单越好；记入待优化 |

### 设计评审

- **评分**：A−（L1 门槛是 B）。扣分项：提示音的音色只定了「短促、安静」，没在设计阶段试听（中）；暗色模式未做、「休息到点」没在工作台单独画（低，打磨项）。
- **AI 模板痕迹**：A。唯一沾边的是「一切居中」——单一焦点的计时页本来就该居中，用光学上移和留白分组避免呆板。
- **0-10 交互审查**（全部 ≥ 8，可以直接实现）：

| 维度 | 分 | 满分标准 | 差什么 |
|---|---|---|---|
| 信息架构 | 9 | 先看什么、再看什么、最后看什么一眼答得出 | 无 |
| 交互状态覆盖 | 8 | Feature Spec 的每个状态都在工作台里画出 | 「休息到点」与「专注到点」对称，没单独画 |
| 用户旅程情感弧线 | 8 | 到点那一刻有被察觉、又不打扰的确认 | 页面只有文字和颜色切换，靠标题与提示音补 |
| AI 模板痕迹风险 | 9 | 放到别的项目里不成立 | 居中布局是题材决定的 |
| 设计体系对齐 | 8 | 站点样式与 DESIGN.md 同源 | 站点级色值要在实现时手写进 `:root` |
| 响应式与无障碍 | 9 | 各尺寸放得下、键盘可用、读屏不吵 | 安全区在实现时补 |
| 未决设计问题 | 8 | 没有含糊处 | 提示音音色、暗色模式 |

### 影响范围

- 新增组件：剩余时间、阶段标签、状态说明、主按钮、跳过按钮、今日完成数、存储提示、标签页标题
- 新增 Token：语义色 13 个与 `--font-sans`（站点级）；`--pomo-*` 页面级与组件级（见 `pomodoro.tokens.css`）
- 修改 Token：无（首版）
- 影响页面：番茄钟页面（唯一页面）
- 设计产物：`docs/assets/visuals/pomodoro/`（工作台页面包与气质稿）、`docs/assets/visuals/_workbench/`（工作台引擎副本）、根目录 `pomodoro.tokens.css`
